Untuk Mengambil Data (Universal/Kolom Tertentu):

const respon = await window.DashboardSecurityContext.panggilMandorFrontend({
    aksi: 'ambil_data',
    target_tabel: 'nama_tabel_anda',
    kolom_diminta: ['kolom_A', 'kolom_B'], // Opsional: Hapus baris ini jika ingin tarik semua kolom
    role_diizinkan: 'owner.adminmaster'    // Opsional: Hapus baris ini jika boleh dibuka semua role
});

Untuk Menambah Data Baru (INSERT):

const respon = await window.DashboardSecurityContext.panggilMandorFrontend({
    aksi: 'tambah_data',
    target_tabel: 'nama_tabel_anda',
    data_input: {
        nama_kolom_db1: 'Nilai Input 1',
        nama_kolom_db2: 'Nilai Input 2'
    }
});

Untuk Menghapus Data Berbasis ID (DELETE):

const respon = await window.DashboardSecurityContext.panggilMandorFrontend({
    aksi: 'hapus_data',
    target_tabel: 'nama_tabel_anda',
    id_target: 5 // Masukkan angka ID baris yang ingin didepak
});

1. Folder live-monitoringMengurusi sirkuit data pemantauan berkala stasiun kerja yang sedang aktif.live-monitoring.controller.js: Menerima perintah dari mandor-backend.js (aksi CHECK_HEARTBEAT_AND_DEVICES), membersihkan data, dan memformat array agar siap dikonsumsi oleh tabel HTML dashboard.live-monitoring.repository.js: Berisi kueri SQL mentah untuk berkomunikasi dengan PostgreSQL guna menarik data relasi seluruh komputer dari tabel users_devices.🛡️ 
2. Folder render-policyMengurusi pembatasan menu visual berdasarkan tingkatan jabatan (Role-Based UI Isolation).render-policy.controller.js: Membaca variabel currentSessionRole yang dikirim dari main.js, lalu menentukan aturan grafis apa saja yang boleh dilihat (misal: jika role user, maka tombol reset akan dihancurkan dari layar visual).render-policy.dto.js: Data Transfer Object yang bertugas mengunci struktur data polis agar format objek yang dikirim ke frontend selalu seragam dan aman dari anomali.
3. Folder reset-hardwareFitur darurat (Emergency Brake) untuk membersihkan seluruh data binding komputer.reset-hardware.controller.js: Menangani perintah pembersihan. Karena ini aksi sakral, kontroler ini memastikan bahwa kueri hanya berjalan jika gerbang main.js mengonfirmasi pelakunya adalah owner/adminmaster.reset-hardware.repository.js: Berisi kueri SQL mutlak TRUNCATE TABLE users_devices untuk menyapu bersih seluruh baris stasiun kerja karyawan di PostgreSQL dalam satu detik jika terjadi pelanggaran keamanan massal.
4. Folder settings (Pengaturan Perangkat)Folder ini dibagi menjadi dua sub-fitur untuk mengurusi pendaftaran komputer baru milik karyawan:A. Sub-Folder get-verified-devices (Mengambil Perangkat Sah)Membaca database untuk memisahkan mana laptop/PC karyawan yang statusnya sudah sah disetujui, dan mana stasiun kerja yang masih berstatus terkunci/pending.
B. Sub-Folder verify-device (Otorisasi Aktivasi OTP Perangkat Baru)verify-device.controller.js: Menyaring input kiriman kode aktivasi dari panel Admin di frontend.verify-device.service.js: Otak bisnis fitur. Bertugas memeriksa apakah panel sedang dibekukan akibat salah ketik berulang kali (anti-brute-force), lalu mencocokkan kode OTP. Jika cocok, hitungan kesalahan di-reset kembali ke 0.verify-device.repository.js: Mengeksekusi query SQL UPDATE ke database untuk mengubah status perangkat terkait menjadi is_verified = TRUE setelah kodenya dinyatakan sah oleh bagian service.

1. 📄 feature.dto.js (Lapis 1: Satpam Validasi Objek)Tugas: Menyaring objek data (payload) yang baru masuk dari frontend.Aturan: File ini memastikan apakah variabel yang dikirim tipenya benar (misal: ID harus angka, OTP harus string). Jika salah, data langsung ditolak di sini sebelum membebani database.
2. 📄 feature.controller.js (Lapis 2: Polisi Lalu Lintas Data)Tugas: Menerima data dari mandor-backend.js, menyerahkannya ke DTO untuk diperiksa, lalu melemparkannya ke Service.Aturan: Tidak boleh ada query database atau logika bisnis di sini. Tugasnya hanya mengontrol alur masuk-keluar data.
3. 📄 feature.service.js (Lapis 3: Otak Logika Bisnis)Tugas: Melakukan perhitungan, pengecekan hak akses, pemotongan string, manipulasi keamanan (anti-brute-force), atau panggilan API luar.Aturan: Ini adalah tempat menulis rumus matematika dan aturan bisnis aplikasi Anda. Jika logika selesai, dia memanggil Repository untuk menyimpan hasilnya.
4. 📄 feature.repository.js (Lapis 4: Tukang Gali Database)Tugas: Menulis string query SQL mentah (SELECT, INSERT, UPDATE, DELETE) menggunakan dbPool.Aturan: Hanya boleh berisi perintah komunikasi mentah ke PostgreSQL. File ini tidak boleh tahu apa itu token JWT atau logika bisnis, dia hanya patuh mengeksekusi perintah SQL.
